# Ferramenta de controle de investimento em Excel.
  Projeto desenvolvido como desafio prático na plataforma da DIO.

## Objetivos do Projeto
- Simulação e controle de investimento.
- Cálculo de rendimento mensal e previsão de dividendos.
- Organização e estruturação visual no Excel.

# Recursos e Fórmulas utilizadas 
  Cálculos matemáticos
  Fórmulas VF;PROCV
  Validação de dados
  Tabela de apoio
  Formatação de cores 


 É uma ferramenta criada no Excel para simular investimentos.
 O usuário insere dados como valor mensal, prazo e taxa e a planilha calcula cenários futuros.
